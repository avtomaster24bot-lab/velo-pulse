# 🚲 ВелоПульс

**Вело-контент каждый день**: 7 постов о велосипедах — с аудио-рассказом, каруселью слайдов для Instagram/Telegram и вертикальным видео для Reels / Shorts / TikTok.

🌐 Сайт: https://avtomaster24bot-lab.github.io/velo-pulse/
📢 Telegram: https://t.me/velopark_kz
📰 RSS / подкаст: https://avtomaster24bot-lab.github.io/velo-pulse/feed.xml

## Рубрики (каждый день по плану)
1. 📰 **Новости велоспорта**: Cyclingnews, VeloNews, Cycling Weekly, road.cc (RSS, свежие за 3 дня).
2. ⚡ **Новинки и технологии**: Bikerumor, DC Rainmaker, Pinkbike.
3. 🏆 **Звёзды и гонки**: Википедия (велогонщики Казахстана, победители Гранд-туров, легендарные гонки).
4. 📜 **История и факты** / 🚲 **Типы велосипедов**: справочник [Вело-вселенная](https://avtomaster24bot-lab.github.io/velo-universe/).
5. ⚙️ **Техника** / 🔧 **Обслуживание и ремонт**: справочник Вело-вселенная (детали, инструкции, инструмент).
6. 🗺️ **Маршруты и путешествия**: каталог [Velopark](https://avtomaster24bot-lab.github.io/velopark/), чаще Казахстан и Центральная Азия.
7. 💪 **Тренировки и здоровье** / 🦺 **Безопасность** / 💡 **Лайфхаки**: статьи Википедии + справочник неисправностей.

## Как это работает
```
GitHub Actions (каждый день 03:00 UTC = 08:00 Алматы)
 ├─ scripts/generate.py   источник → пост на русском (ИИ пишет только по фактам источника)
 │                        → второй проход: фактчек и редактура
 │                        → фото с Wikimedia Commons (свободные лицензии), ИИ отбирает только подходящие по теме
 ├─ scripts/make_media.py слайды 1080×1350 PNG (обложка + 4 + финал) и ZIP, аудио (edge-tts),
 │                        видео 1080×1920 со слайдами и субтитрами, тексты для соцсетей → GitHub Release day-ДАТА
 ├─ коммит data/*.json, feed.xml
 ├─ scripts/telegram.py   альбом-карусель + подпись + аудио в @velopark_kz (если задан TELEGRAM_BOT_TOKEN)
 └─ деплой сайта на GitHub Pages (медиа за 10 дней — на сайте, старые — из Releases)
```
ИИ: GitHub Models (бесплатно внутри GitHub Actions, `gpt-4.1` / `gpt-4.1-mini`), запасной вариант — Pollinations.ai без ключа,
или свой OpenAI-совместимый API (секреты `LLM_API_URL`, `LLM_API_KEY`, `LLM_MODEL`).

## Настройки
- `topics.json`: рубрики, план дня, RSS-ленты, категории Википедии, голос, канал Telegram.
- `bank/bank.json`: банк проверенных тем (детали, ремонт, история, маршруты), собирается `scripts/build_bank.py` из справочников Вело-вселенная и Velopark.
- Секрет `TELEGRAM_BOT_TOKEN`: токен бота (бот должен быть админом канала). Переменная `TELEGRAM_CHAT_ID` (по умолчанию `@velopark_kz`), `TELEGRAM_SEND_VIDEO=1`, если нужны ещё и видео.
- Ручной запуск: Actions → «Ежедневный ВелоПульс» → Run workflow (можно пересобрать день). «Отправить в Telegram» отправляет выбранный день повторно (уже отправленные посты пропускаются).
